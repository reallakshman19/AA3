### Controller mutation owner

- retains one `emp1EngineeringReviewRecord` in controller session state;

- supplies reviewed timestamp from a controller clock and fixed review basis code from the adapter;
- leaves retained review in place across source/rerun changes so the core stale detector can invalidate it;
