## Material result

The remaining shell linear-solver scalability implementation is now source-complete on draft PR #1541 without changing CST/DKT formulation, MITC route authority, load mapping, recovery definitions, tolerances, registry, or UI.

### Shared numerical ownership

New `src/core/lafea-linear-solve/pcg.js` is the single deterministic Jacobi-preconditioned PCG owner. It retains the already-established continuum mechanics:

- `DETERMINISTIC_JACOBI_PCG_RELIABLE_RESIDUAL_V2` algorithm identity;
- Jacobi preconditioning;
- reliable/exact residual replacement every 100 iterations;
- internal convergence target = caller's residual acceptance tolerance / 10;
- iteration limit = `min(50000, max(1000, 16*n))`;
- positive diagonal, residual-product and curvature fail-closed checks;
- final exact residual verification;
- explicit non-convergence failure.

The shared module receives matrix size, diagonal, RHS, matrix-vector action, diagonal tolerance and residual tolerance. It imports no continuum, shell, load, recovery, registry or UI authority.

### Continuum preservation

`src/core/local-continuum/solver.js` no longer contains a second private PCG recurrence. Its adapter computes the same existing `choleskyPivot` and `freeDofResidual` tolerances, calls the shared owner, then reconstructs the existing continuum evidence schema and maps shared failure states back to the same continuum `INDEFINITE_FREE_STIFFNESS`, `UNDER_CONSTRAINED_OR_SINGULAR_SYSTEM`, and `ITERATIVE_SOLVER_DID_NOT_CONVERGE` authority.

Dense continuum Cholesky and all continuum model/load/recovery logic are unchanged.

### Shell scalable route

`src/core/local-shell/solver.js` now uses shared Jacobi-PCG for sparse shell storage. Small shell systems retain `DETERMINISTIC_DENSE_CHOLESKY`.

Shell formula trace is now method-aware:

- dense solve -> `FORMULA_IDS.CHOLESKY`;
- sparse PCG -> `FORMULA_IDS.PCG`;
- fully constrained -> neither.

Structural PCG failures map to `ShellSingularSystemError`; PCG non-convergence maps to `ShellNumericalError`. No tolerance is changed or invented.

### Result-contract custody

`src/core/local-shell/result-validation.js` accepts the explicit PCG evidence shape while preserving the old direct-solver evidence shape. PCG algorithm revision is imported from the shared owner rather than duplicated as an independent string authority.

### Independent/falsifier evidence added

`scripts/lafea.11-pcg-shared-check.mjs` adds an independent analytical SPD oracle:

`[[4,1],[1,3]] x = [1,2]` -> exact `x = [1/11, 7/11]`.

It also contains controls for singular diagonal, negative/indefinite diagonal, non-positive curvature, explicit non-convergence and deterministic repeated execution.

`scripts/lafea.11-determinism-check.mjs` and `lafea-solver-determinism-worker.mjs` now include PCG in the existing in-process and cross-process byte-identity solver gate. Therefore `npm run check:lafea-solver` exercises PCG determinism without a new parallel aggregate.

`scripts/lafea.4-solver-loads-check.mjs` requires forced-sparse shell solve to match dense displacement, reaction, membrane/bending/global energy and recovered stress/von-Mises within the existing test tolerance; automatic >1536-DOF routing must identify `DETERMINISTIC_JACOBI_PCG`, carry V2/Jacobi evidence and contain PCG rather than Cholesky in formula trace. Sparse singular behavior remains fail closed.
