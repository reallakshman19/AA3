## Material change

EP-0019 closed engineer-facing reaction aggregation for a valid node that carries both a scalar rigid support and a grounded directional spring. A follow-on production audit traced the remaining raw-reaction consumer in the native LFEA analysis controller: the post-solve one-way/unilateral restraint accuracy review.

`inputxml-linear-unilateral-restraint-review.js` previously built a last-write-wins map from raw `execution.reactions`. On a reviewed one-way DOF that also carries a grounded directional spring component, raw execution can contain both the constrained one-way-support reaction and the spring action at the same `nodeId:dof`. The map could therefore inspect the spring row instead of the one-way support's own action and falsely declare lift-off/consistency depending on row order.

Summing the two is not physically valid for this check: lift-off concerns the one-way support's own reaction, not total support action at the physical node.

## Landed fix

The review schema and solver reaction evidence remain unchanged. The reviewer now:

1. algebraically sums the retained raw support contributions per node/DOF;
2. detects whether any reviewed one-way DOF overlaps a grounded directional spring in the compiled mechanical model;
3. when overlap exists, requires solved displacement evidence;
4. reconstructs each grounded directional spring action exactly from the compiled `k`, exact unit direction `n` and solved translation `u` using `-k(n·u)n`;
5. subtracts the overlapping spring action from the retained support total, isolating the one-way support's constrained reaction before applying the resisted-sign/lift-off test;
6. fails closed with `INPUTXML_UNILATERAL_REVIEW_DISPLACEMENT_REQUIRED` if mixed-support displacement evidence is unavailable.

`lfea-pipeline-analysis-controller.js` now passes the sealed execution displacement rows to the review. Ordinary unilateral-only calls retain the existing two-argument path because no spring decomposition is required.

New `scripts/lfea-unilateral-mixed-reaction-review-check.mjs` proves in source-authored custody that:

- a +10 N one-way support remains CONSISTENT even when an overlapping skew spring contributes an opposite-sign UX reaction;
- a true -10 N one-way support remains `LINEARIZATION_EXCEEDED` after spring-action removal;
- the reported violation reaction is the isolated -10 N one-way action, not the spring row or algebraic total;
- mixed support without displacement evidence fails closed;
- ordinary unilateral-only two-argument review remains compatible;
- deliberate-break mode makes the otherwise-consistent case expect the wrong verdict and must turn red.

The guard is imported by `lfea-spring-draft-model-check.mjs` and is not orphan coverage.
