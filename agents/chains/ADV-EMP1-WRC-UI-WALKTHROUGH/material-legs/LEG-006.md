## Evidence journey

The Playwright journey drives only existing user-visible controls and attaches 12 full-page PNG checkpoints:

1. cold start / fail closed
2. qualification bundle current
3. Basis & Source
4. Geometry
5. Loads
6. Load Transfer
7. Section Screening
8. Local Correlation configuration
9. current WRC result / governing scope
10. Review & Evidence
11. governed upstream A geometry edit
12. stale downstream C result with reason/action

The stale-state mutation uses the existing governed `Pipe outside diameter LAFEA.1` textbox plus the visible `PIPE_GEOMETRY` apply-group action. No private store mutation or WRC numerical override is used.
