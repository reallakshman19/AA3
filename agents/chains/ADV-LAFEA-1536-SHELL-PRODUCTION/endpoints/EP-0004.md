## Mission

Close the remaining shell solve-scalability boundary by reusing the already-qualified deterministic Jacobi-PCG mechanics that exist in `src/core/local-continuum/solver.js`, moving the storage-independent iterative algorithm into the governed shared `src/core/lafea-linear-solve/**` numerical owner, preserving continuum behavior, and making sparse LAFEA.4 production solves consume that same owner.

## Why this is the next safe boundary

The current shell branch removes dense global-matrix storage but still uses sparse-direct Cholesky. That implementation has no fill-reducing ordering and scans a quadratic elimination space. The continuum production route already has a deterministic Jacobi-PCG implementation with:

- positive-diagonal/singularity screening;
- positive-curvature checks;
- deterministic iteration cap `min(50000, max(1000, 16*n))`;
- internal convergence target `freeDofResidualTolerance / 10`;
- exact/reliable residual replacement every 100 iterations;
- explicit non-convergence failure.

Copying that implementation into `local-shell` would create duplicate numerical authority. Extraction to `lafea-linear-solve` is therefore the intended owner boundary.
