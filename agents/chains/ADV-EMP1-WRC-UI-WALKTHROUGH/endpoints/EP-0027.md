## Concrete mismatch

Issue #1559 Definition of Done requires the walkthrough to be **human-observed (or recorded)** and explicitly states that a passing Playwright script is insufficient on its own. It also requires inspection of transitions, not merely endpoint screen states.

The current human walkthrough document says a qualified reviewer may `inspect those artifacts or observe the run live` and its PASS section can therefore be read as allowing final PASS from static viewport/full-page/ARIA artifacts alone.

That is weaker than #1559. Static artifacts are necessary per-stage evidence, but they cannot establish dynamic transition behavior such as transient task loss, unexpected movement, flicker, or interaction-dependent behavior between checkpoints.

This is an acceptance-policy/evidence defect only. No production UI defect is asserted.

## Minimal authorized correction

1. Preserve all 12 viewport, 12 full-page, and 12 ARIA evidence artifacts.
2. Keep them as required per-stage evidence.
3. Make final #1559 PASS require one of:
   - a qualified human reviewer observes the actual walkthrough live; or
   - a qualified human reviewer reviews a recording that captures the actual walkthrough transitions/interactions.
4. Static artifact-only review may support a PARTIAL disposition but cannot establish final PASS.
5. Add the same rule to the machine-readable manifest so downstream consumers cannot mistake artifact completeness for acceptance.
6. Preserve the existing hover-only rule: if tooltip meaning is interaction-only, it must be observed live/recorded.
