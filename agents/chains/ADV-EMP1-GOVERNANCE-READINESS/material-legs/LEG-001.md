## Changed production boundary

Added `src/core/emp1/emp1-readiness-projection.js`.

Responsibility is limited to composing an already-governed `emp1-product-projection/v1` into deterministic readiness states. It does not import WRC evaluators, tables, datasets, route executors, source-authority modules, release executors or workspace UI code.

The projection preserves separate states for:

- source/input currentness;
- bounded method authority;
- applicability evidence;
- calculation currentness;
- engineering review;
- code compliance;
- release qualification.

Pre-run applicability is projected only as `PENDING_EXECUTION_GATE`. Applicability becomes `QUALIFIED_BY_CURRENT_EXECUTION_GATE` only when the governed C projection reports a current result. Stale retained C evidence cannot become current applicability authority.

## Checker
