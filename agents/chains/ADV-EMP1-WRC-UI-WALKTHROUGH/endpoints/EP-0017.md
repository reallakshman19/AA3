## Observed acceptance gap

Issue #1559 requires a human-observed or recorded browser walkthrough with evidence per stage. Current Playwright configuration retains screenshots only on failure and video only when explicitly enabled, while the existing WRC browser spec proves behavior without attaching passing-run review evidence. The repository's `3d-simplified-full-workflow.spec.js` provides a deterministic full-workflow benchmark but likewise does not supply passing-stage screenshots.

This is an acceptance-evidence gap, not a WRC numerical or production-UI defect.

- Add a dedicated `e2e/emp1-professional-walkthrough-evidence.spec.js` that reuses the production workbench fixture and real qualification sample, captures 12 named full-page checkpoints as Playwright attachments, and exercises an upstream governed A-source edit to prove the downstream C result becomes stale with a visible reason/action.
