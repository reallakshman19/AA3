# ASME B31J-2023 Standard Benchmark Reference
## Stress Intensification Factors (SIFs), Flexibility Factors ($k$), and Moment-Rotation Relationships

---

### Executive Summary & Scope

This document provides the standard reference equations, flexibility factors, stress intensification factors (SIFs), sustained stress multipliers, moment-rotation stiffnesses, flanged end corrections, and geometric applicability limits extracted from **ASME B31J-2023** (*Standard Test Method for Determining Stress Intensification Factors (i-Factors) for Metallic Piping Components*).

---

## 1. Table 1-1: Flexibility and Stress Intensification Factors

All flexibility factors ($k$) and stress intensification factors ($i$) shall be $\ge 1.0$ unless explicitly noted.

## 2. Table 1-2: Moment-Rotation Relationships for Branch Connections (Sketches 2.1 – 2.6)

Rotational spring relationships are modeled as $K = \frac{M}{\theta}$:

| Applied Moment (Figure 1-1) | Flexibility Factor ($k$) | Flexibility Rotation Ratio | Rotational Stiffness ($K$) |
| :--- | :--- | :--- | :--- |
| **$M_{i3}$ (Branch Leg 3 In-Plane)** | $k_{ib}$ | $M_{ib} / \theta_{ib}$ | $$K_{ib} = \frac{E I_b}{k_{ib} \, d}$$ |
| **$M_{o3}$ (Branch Leg 3 Out-of-Plane)** | $k_{ob}$ | $M_{ob} / \theta_{ob}$ | $$K_{ob} = \frac{E I_b}{k_{ob} \, d}$$ |
| **$M_{t3}$ (Branch Leg 3 Torsional)** | $k_{tb}$ | $M_{tb} / \theta_{tb}$ | $$K_{tb} = \frac{E I_b}{k_{tb} \, d}$$ |
| **$M_{i1,2}$ (Run Legs 1, 2 In-Plane)** | $k_{ir}$ | $M_{ir} / \theta_{ir}$ | $$K_{ir} = \frac{E I_r}{k_{ir} \, D}$$ |
| **$M_{o1,2}$ (Run Legs 1, 2 Out-of-Plane)** | $k_{or}$ | $M_{or} / \theta_{or}$ | $$K_{or} = \frac{E I_r}{k_{or} \, D}$$ |
| **$M_{t1,2}$ (Run Legs 1, 2 Torsional)** | $k_{tr}$ | $M_{tr} / \theta_{tr}$ | $$K_{tr} = \frac{E I_r}{k_{tr} \, D}$$ |

> **GENERAL NOTE (Table 1-2)**: The moment-rotation relationships in this table are developed by independently applying moments to the respective run or branch leg. Simultaneous run and branch moment-rotation interaction must be accommodated by the model.

## 3. Table 1-3: Flanged End Correction Coefficients for Branch Connections (Sketches 2.1 – 2.6)

When flanges or other rigid components are attached within a distance less than $0.1 D^{1.4} / T^{0.4}$ from the branch connection, the branch flexibility factors $k_{ib}, k_{ob}, k_{tb}$ are multiplied by $c$:

$$k_{\text{corrected}} = c \cdot k$$

| Flexibility Factor | Flanged End Multiplier Coefficient ($c$) |
| :--- | :--- |
| **$k_{ib}$ (Branch In-Plane)** | $$c = 1 - 0.032 \, N_c^{1.345} \left(\frac{D}{T}\right)^{0.431} \left(\frac{d}{D}\right)^{0.903}$$ |
| **$k_{ob}$ (Branch Out-of-Plane)** | $$c = 1 - 0.07 \, N_c^{0.61} \left(\frac{D}{T}\right)^{0.44} \left(\frac{d}{D}\right)^{0.339}$$ |
| **$k_{tb}$ (Branch Torsional)** | $$c = 1 - 0.003 \, N_c^{3.962} \left(\frac{D}{T}\right)^{0.548} \left(\frac{d}{D}\right)^{0.693}$$ |

where $N_c$ is the number of flanged run ends ($N_c = 1$ or $2$).

### General Notes (b) through (e)

- **(b) Limits of Validity**: Stress intensification and flexibility factor data in this table shall be used in the absence of more directly applicable data. Validity has been demonstrated for $D/T \le 100$. SIFs and flexibility factors shall not be less than $1.0$. SIFs may be used without flexibility factors. Developed from fatigue tests of ductile ferrous materials and finite elements.
- **(c) Maximum SIF Option**: The highest in-plane or out-of-plane SIF shall be used when only a single SIF is needed. Flexibility factors should always be used with the orientation specified.
- **(d) Sustained Stress Multipliers ($B_1, B_2$ or sustained moment index)**: Where sustained stress or moment factors are required by the applicable Code (e.g., ASME B31.1, ASME B31.3), in lieu of more applicable data:
  - For Sketches 1.1–1.3 and 3.1–5.1: The directional sustained stress or moment multiplier is taken as the component SIF ($i$).
  - For Sketches 2.1–2.6 (Branch connections): The directional sustained stress multiplier is taken as the smaller of:
    1. $0.75 \times i$ (where $i$ is the applicable SIF)
    2. $(t/T) \sqrt{i}$ (when $t/T > 1$)
    3. $\sqrt{i}$ (when $t/T \le 1$)
  - Sustained stress factors shall not be less than $1.0$ and are used with matching pipe section modulus.
  - When $D_o/T > 50$, divide sustained stress multiplier by $(1.3 - 0.006 D_o/T)$.
- **(e) Nonstandard Components**: For unlisted piping components (valves, strainers, eccentric reducers, nonstandard fittings), SIFs and flexibility factors can be established via finite element method or documented test results.

## 5. Specific Notes (1) through (13)

- **Note (1)**: SIFs and flexibility factors apply over the effective arc length (heavy centerlines in sketches). Branch SIFs apply to the intersection point for Legs 1 and 2 ($d_o/D_o > 0.5$) or to the branch centerline at the surface of run pipe ($d_o/D_o \le 0.5$).
- **Note (2)**: Where flanges or rigid components are attached to one or both ends of bends/miters, multiply $k$ and $i$ by factor $c$ from Figure 1-5 ($c_1 = h^{1/6}$ for one flanged end, $c_2 = h^{1/3}$ for two flanged ends).
- **Note (3)**: When bend angle is $90^\circ$ and thickness equals matching pipe, $k_i = k_o = 1.3/h$ (adjusted by $c$).
- **Note (4) Pressure Correction for Bends/Elbows**: In large-diameter thin-wall elbows/bends, internal pressure $P$ reduces $k$ and $i$:
  - Divide $k$ by:
    $$\left[1 + 6 \left(\frac{P}{E}\right)\left(\frac{R}{T}\right)^{7/3}\left(\frac{R_1}{R}\right)^{1/3}\right]$$
  - Divide $i$ by:
    $$\left[1 + 3.25 \left(\frac{P}{E}\right)\left(\frac{R}{T}\right)^{5/2}\left(\frac{R_1}{R}\right)^{2/3}\right]$$
- **Note (5)**: Sketch 1.3 includes single miter joints.
- **Note (6)**: Sketch 2.1 SIFs are based on components free of defect/creases. Sketch 2.3 SIFs may be used as an alternative:
  - (a) If $r_x \ge \frac{1}{8} d_o$ and $T_c \ge 1.5T$, $k$ and $i$ may be divided by $1.26$.
  - (b) If $t/T < 0.6$, use $t/T = 0.6$ for all branch $k$ and $i$.
- **Note (7) Branch Conditions**:
  - (a) Branch pipe axis is normal to run pipe within $5^\circ$.
  - (b) $R/T \le 50$.
  - (c) $d/D \le 1.0$.
  - (d) $r/t \le 50$.
  - (e) Straight run pipe maintained $\ge 2D$ on each side of branch.
  - (f) For Sketches 2.1, 2.4, 2.5: $t/T \le 1.2$ and $T_c/T \ge 1.1$.
  - When $k \le 1.0$, stiffness is rigid. When flanged run pipe length $< 0.1 D^{1.4}/T^{0.4}$, multiply branch flexibility factors by Table 1-3 factor $c$.
  - Branch connection SIFs and flexibility factors shall not exceed Sketch 2.3 / Figure 1-3(d) with $r_2 = 0$, nor be less than Sketch 2.1 with $T_c = 1.1T$.
  - If $i_{ob} < i_{ib}$, use $i_{ob} = i_{ib}$. If $i_{tr} < i_{or}$, use $i_{tr} = i_{or}$.
  - For $D/T \ge 25$, $i_{ob}$ multiplier: larger of $[0.75(t/T) - 0.89(t/T)^2 + 0.18](D/T)^{0.34}$ or $1.0$ (Sketch 2.3), $[1.07(t/T) - 1.08(t/T)^2 + 0.026](D/T)^{0.34}$ or $1.0$ (Sketch 2.2).
- **Note (8) Unreinforced Tees with Outer Radius**: Multiply SIFs by $0.7$ when $r_2 \ge \min(T/2, t/2, (r_p - r_i)/2, (t + y)/2)$. Compute $t'$ and $d'$ per Figure 1-3.
- **Note (9) Extruded Outlets**: If $r_x$ not provided, $r_x = 0.05d_o$. If $r_x \ge r$, use $r_x = r$. If $t/T < 0.6$, use $t/T = 0.6$.
- **Note (10) Weldolets / Integrally Reinforced Fittings**: If $r/r_p < 0.6$, use $0.6$. If $D/T < 40$, $i_{ob} \times 0.75$.
- **Note (11) Reducer Conditions**:
  - $5^\circ < \alpha < 60^\circ$
  - $5 < D_2/T_2 < 80$
  - Thickness $\ge T_1$ in body and $T_2$ at small end.
  - $0.08 < r_2/D_2 < 0.7$
  - $1 < T_1/T_2 < 2.12$
  - If $L_2 < (D_2 T_2)^{0.5}$, multiply SIFs by $[2 - L_2/(D_2 T_2)^{0.5}]$.
  - Max SIF $\le 2.0$.
- **Note (12) Girth Butt Welds**: Applies to welds between items whose thicknesses are between $0.875T$ and $1.10T$ for distance of $(D_o T)^{1/2}$. $\delta_{\text{avg}}$ is average mismatch.
- **Note (13) Socket-Welded Flanges/Fittings**: $C_x$ weld size per code. For pipe thinner than schedule 40 / standard weight, SIF in all directions equals $2.1$ unless justified.
