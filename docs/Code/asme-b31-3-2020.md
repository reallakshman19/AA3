# ASME B31.3-2020 Benchmark Reference: Appendix D & Table D300 Status
## Flexibility Factors ($k$), Stress Intensification Factors (SIFs), and Transition to ASME B31J

---

### Executive Summary & Code Disposition

In the **ASME B31.3-2020 Edition** (*Process Piping*), **Appendix D (Flexibility and Stress Intensification Factors / Table D300) was officially deleted from the Code**.

#### Official ASME B31.3-2020 Summary of Changes Record:
- **Table 300.4** (Page xxii / Page 10): *Appendix D deleted.*
- **Paragraph 319.3.6** (Page xxii / Page 40): *Revised to reference ASME B31J for flexibility factors and stress intensification factors.*
- **Paragraph 319.4.4** (Page xxii / Page 41): *Subparagraphs (a) and (b) revised; Subparagraph (c) and equations (19) and (20) deleted.*
- **Appendix D** (Page xxvi / Page 412): *Deleted in its entirety.*

This benchmark reference provides:
1. **The Official Status & Transition Notice for ASME B31.3-2020** (directing to [ASME B31J-2017](asme-b31j-2017.md) / [ASME B31J-2023](asme-b31j-2023.md)).
2. **The Complete Historical ASME B31.3 Appendix D (Table D300)** equations, flexibility factors ($k$), in-plane SIFs ($i_i$), out-of-plane SIFs ($i_o$), pressure corrections, and flanged end factors for backward compatibility and legacy verification.
3. **Crosswalk & Comparison** between legacy Table D300 and ASME B31J Table 1-1.

## 1. Legacy ASME B31.3 Appendix D (Table D300) Formulation

All flexibility factors ($k$) and stress intensification factors ($i$) shall be $\ge 1.0$.

### 1.1 Bends and Miters

| Description | Flexibility Characteristic ($h$) | Flexibility Factor ($k$) | In-Plane SIF ($i_i$) | Out-of-Plane SIF ($i_o$) | Notes |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Pipe Bend or Welding Elbow** (ASME B16.9) | $$h = \frac{t \, R_1}{r^2}$$ | $$k = \frac{1.65}{h}$$ | $$i_i = \frac{0.9}{h^{2/3}}$$ | $$i_o = \frac{0.75}{h^{2/3}}$$ | [Notes (1), (2), (3), (7)](#3-table-d300-specific-notes) |
| **Closely Spaced Miter Bend** ($s < r(1 + \tan\theta)$) | $$h = \frac{s \, t \cot\theta}{2 r^2}$$ | $$k = \frac{1.52}{h^{5/6}}$$ | $$i_i = \frac{0.9}{h^{2/3}}$$ | $$i_o = \frac{0.9}{h^{2/3}}$$ | [Notes (1), (2), (4), (7)](#3-table-d300-specific-notes) |
| **Widely Spaced Miter Bend** ($s \ge r(1 + \tan\theta)$) | $$h = \frac{t(1 + \cot\theta)}{2 r}$$ | $$k = \frac{1.52}{h^{5/6}}$$ | $$i_i = \frac{0.9}{h^{2/3}}$$ | $$i_o = \frac{0.9}{h^{2/3}}$$ | [Notes (1), (2), (5), (7)](#3-table-d300-specific-notes) |

#### Internal Pressure Correction for Bends/Elbows [Note (7)]:
For thin-walled large-diameter bends subjected to internal design pressure $P$:
- Corrected Flexibility Factor:
  $$k_p = \frac{k}{1 + 6 \left(\frac{P}{E}\right)\left(\frac{r}{t}\right)^{7/3}\left(\frac{R_1}{r}\right)^{1/3}} \ge 1.0$$
- Corrected In-Plane SIF:
  $$i_{ip} = \frac{i_i}{1 + 3.25 \left(\frac{P}{E}\right)\left(\frac{r}{t}\right)^{5/2}\left(\frac{R_1}{r}\right)^{2/3}} \ge 1.0$$
- Corrected Out-of-Plane SIF:
  $$i_{op} = \frac{i_o}{1 + 3.25 \left(\frac{P}{E}\right)\left(\frac{r}{t}\right)^{5/2}\left(\frac{R_1}{r}\right)^{2/3}} \ge 1.0$$

### 1.2 Branch Connections & Tees

In legacy Appendix D Table D300, all tees and branch connections are modeled with **$k = 1.0$** and a single set of in-plane/out-of-plane SIFs:

$$i_o = \frac{0.9}{h^{2/3}} \ge 1.0, \qquad i_i = 0.75 i_o + 0.25 \ge 1.0$$

| Component Type | Flexibility Characteristic ($h$) | Flexibility ($k$) | In-Plane SIF ($i_i$) | Out-of-Plane SIF ($i_o$) | Notes |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Welding Tee** (ASME B16.9) | $$h = 3.1 \frac{T}{r}$$ | $k = 1.0$ | $$i_i = 0.75 i_o + 0.25$$ | $$i_o = \frac{0.9}{h^{2/3}}$$ | [Note (8), Note (11)](#3-table-d300-specific-notes) |
| **Reinforced Fabricated Tee** ($t_p > 0$) | $$h = \frac{(T + 0.5 t_p)^{5/2}}{T^{3/2} \, r}$$ | $k = 1.0$ | $$i_i = 0.75 i_o + 0.25$$ | $$i_o = \frac{0.9}{h^{2/3}}$$ | [Note (8), Note (9)](#3-table-d300-specific-notes) |
| **Unreinforced Fabricated Tee** | $$h = \frac{T}{r}$$ | $k = 1.0$ | $$i_i = 0.75 i_o + 0.25$$ | $$i_o = \frac{0.9}{h^{2/3}}$$ | [Note (8)](#3-table-d300-specific-notes) |
| **Extruded Outlet** ($r_x \ge 0.05 d_o, T_c > 1.5 T$) | $$h = \left(1 + \frac{r_x}{r}\right)\frac{T}{r}$$ | $k = 1.0$ | $$i_i = 0.75 i_o + 0.25$$ | $$i_o = \frac{0.9}{h^{2/3}}$$ | [Note (8), Note (10)](#3-table-d300-specific-notes) |
| **Welded-In Contour Insert** | $$h = 3.1 \frac{T}{r}$$ | $k = 1.0$ | $$i_i = 0.75 i_o + 0.25$$ | $$i_o = \frac{0.9}{h^{2/3}}$$ | [Note (8)](#3-table-d300-specific-notes) |
| **Branch Welded-On Fitting (Weldolet)** | $$h = 3.1 \frac{T}{r}$$ | $k = 1.0$ | $$i_i = 0.75 i_o + 0.25$$ | $$i_o = \frac{0.9}{h^{2/3}}$$ | [Note (8)](#3-table-d300-specific-notes) |

> *(Note: For verified smooth-radius B16.9 welding tees per Note 11, $h = 4.4 T / r$.)*

## 2. Flanged End Correction Factors ($c_1$)

Where flanges or other rigid attachments are located at one or both ends of bends or miters, the flexibility factor $k$ and SIFs are adjusted by factor $c_1$:

| Configuration | Correction Factor ($c_1$) | Corrected Flexibility | Corrected SIFs |
| :--- | :--- | :--- | :--- |
| **One End Flanged** | $$c_1 = h^{1/6}$$ | $$k_{\text{corr}} = c_1 \cdot k$$ | $$i_{\text{corr}} = \frac{i}{c_1}$$ |
| **Both Ends Flanged** | $$c_1 = h^{1/3}$$ | $$k_{\text{corr}} = c_1 \cdot k$$ | $$i_{\text{corr}} = \frac{i}{c_1}$$ |

## 3. Table D300 Specific Notes

- **Note (1)**: Factors apply over the effective arc length (heavy lines in sketches).
- **Note (2)**: In-plane indicates bending in the plane of the bend or miter; out-of-plane indicates bending perpendicular to the plane of the bend or miter.
- **Note (3)**: For 90-degree elbows, $k = 1.65/h$; $i_i = 0.9/h^{2/3}$; $i_o = 0.75/h^{2/3}$.
- **Note (4)**: Closely spaced miter bends have miter cut spacing $s < r(1 + \tan\theta)$.
- **Note (5)**: Widely spaced miter bends have miter cut spacing $s \ge r(1 + \tan\theta)$.
- **Note (6)**: Factors apply only to ductile ferrous materials with $D/t \le 100$.
- **Note (7)**: Pressure stiffening formula applies for internal pressure $P$, pipe mean radius $r$, thickness $t$, bend radius $R_1$, and elastic modulus $E$.
- **Note (8)**: When branch size $d < D$, the section modulus of the branch pipe $Z_b = \frac{\pi}{32}\frac{d_o^4 - d_i^4}{d_o}$ is used for branch leg stresses, and matching pipe section modulus $Z$ is used for run leg stresses.
- **Note (9)**: For reinforced fabricated tees, pad thickness $t_p$ is included in $h = (T + 0.5 t_p)^{5/2} / (T^{3/2} r)$ up to $t_p \le 1.5 T$.
- **Note (10)**: For extruded outlets, $r_x$ is the crotch radius $\ge 0.05 d_o$.
- **Note (11)**: When ASME B16.9 welding tee has verified smooth crotch transition radius $r_x \ge 0.1 d_o$, $h = 4.4 T / r$ may be used.

## 4. ASME B31.3 Appendix D vs. ASME B31J Comparison Crosswalk

| Feature / Component | Legacy ASME B31.3 Appendix D (Pre-2020) | ASME B31J (2017 / 2023 / B31.3-2020+) |
| :--- | :--- | :--- |
| **Standard Status** | Deleted in B31.3-2020 | **Governing reference for B31.3-2020+** |
| **Branch Flexibility ($k$)** | Rigid ($k = 1.0$) for all branch connections | Fully flexible 6-DOF rotational spring equations ($k_{ib}, k_{ob}, k_{tb}, k_{ir}, k_{or}, k_{tr}$) |
| **Branch Directional SIFs** | Single formula set ($i_o = 0.9/h^{2/3}$, $i_i = 0.75i_o + 0.25$) applied equally to run & branch | Independent directional SIFs for Run ($i_{ir}, i_{or}, i_{tr}$) and Branch ($i_{ib}, i_{ob}, i_{tb}$) |
| **Reducer SIFs** | Unity ($i = 1.0$) | Geometry-dependent formula based on cone angle $\alpha$, $D_2/T_2$, and $r_2$ (SIFs up to $2.0$) |
| **Smooth 90° Elbows** | $k = 1.65/h$ | $k = 1.3/h$ (Table 1-1 Note (3)) |
| **Flanged Branch Ends** | No branch correction factor | Multiplier $c$ from Table 1-3 when straight pipe $< 0.1 D^{1.4}/T^{0.4}$ |
| **Sustained Stress Multipliers** | Not explicitly separated | Multiplier $0.75i$, $(t/T)\sqrt{i}$, or $\sqrt{i}$ with thin-wall reduction $(1.3 - 0.006 D_o/T)$ |

## 5. Table D300 Nomenclature

- $D_o$: Outside diameter of matching run pipe, $\text{in.}$ ($\text{mm}$).
- $d_o$: Outside diameter of branch pipe, $\text{in.}$ ($\text{mm}$).
- $E$: Modulus of elasticity at design temperature, $\text{psi}$ ($\text{kPa}$).
- $h$: Flexibility characteristic (dimensionless).
- $i, i_i, i_o$: Stress intensification factors (dimensionless).
- $k$: Flexibility factor (dimensionless).
- $P$: Internal gage design pressure, $\text{psi}$ ($\text{kPa}$).
- $r$: Mean radius of matching pipe: $r = (D_o - t)/2$, $\text{in.}$ ($\text{mm}$).
- $R_1$: Bend radius of elbow or pipe bend, $\text{in.}$ ($\text{mm}$).
- $r_x$: Crotch radius of extruded outlet or fitting, $\text{in.}$ ($\text{mm}$).
- $s$: Miter spacing at centerline, $\text{in.}$ ($\text{mm}$).
- $T, t$: Nominal wall thickness of pipe or fitting, $\text{in.}$ ($\text{mm}$).
- $t_p$: Thickness of reinforcing pad or saddle, $\text{in.}$ ($\text{mm}$).
- $\theta$: One-half angle between adjacent miter axes, $\text{deg}$.
- $Z$: Section modulus of matching pipe, $\text{in.}^3$ ($\text{mm}^3$).
- $Z_b$: Section modulus of matching branch pipe, $\text{in.}^3$ ($\text{mm}^3$).
