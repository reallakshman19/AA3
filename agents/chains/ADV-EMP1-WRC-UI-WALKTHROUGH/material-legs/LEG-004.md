## Defect
When A/B were loaded/current but governed C source binding remained `SOURCE_INCOMPLETE`, the seven-step workflow could display `Basis & Source · SOURCE CURRENT` while `Geometry · SOURCE INCOMPLETE`.

## Repair
`sourceCurrentness(a,b,c)` now consumes the already-governed C state overlay. Precedence is:
1. both A/B absent -> `SOURCE INPUT REQUIRED`;
2. one A/B absent -> `SOURCE INCOMPLETE`;
3. known stale B custody -> `SOURCE STALE`;
4. C source binding incomplete -> `SOURCE INCOMPLETE`;
5. otherwise -> `SOURCE CURRENT`.

This preserves stale A→B custody as the most specific source-basis defect while preventing incomplete C source binding from being mislabeled current. `ROUTE_SUSPENDED` does not alter source currentness; it remains a separate local-method authority blocker.
