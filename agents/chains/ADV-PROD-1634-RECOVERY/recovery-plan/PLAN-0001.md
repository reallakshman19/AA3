# Detailed recovery plan — production boot, UI/layout, and FEA qualification

## 1. Recovery objective

Recover `Advanced_Analysis` to a state where a production-built application boots reliably, remains inside the existing bundle budget, exposes a usable and authority-correct engineering UI, and has reproducible LAFEA shell verification against independent manual and published calculations.

The plan deliberately separates:

```text
build/runtime integrity
→ UI/layout integrity
→ numerical verification
→ published validation
→ exact-head CI/release evidence
```

A green later layer cannot waive a red earlier layer. A UI pass cannot qualify mechanics; a benchmark pass cannot repair a production startup crash; a source review cannot turn NOT_RUN into PASS.

### LEG-006 — manual analytical benchmark pack

Create an independent oracle module/document that does not import the production shell element implementation.

#### BM-001 rotated affine membrane

- impose a global affine displacement field on at least two differently oriented facets;
- derive global engineering strain analytically;
- derive plane-stress response independently;
- rotate the analytical tensor into each facet local frame;
- compare local components;
- separately project production local tensors back into a declared global/physical direction.

**Acceptance:** component errors within arithmetic tolerance; stress invariants and energy density agree; test fails if global components are compared directly to rotated local components.

#### BM-002 rigid motion

Rigid translation + infinitesimal rigid shell rotation.

**Acceptance:** zero strain/curvature/stress/internal energy within scale-aware tolerance, while nodal displacements/rotations are nonzero.

#### BM-003 pure bending

Use prescribed `kappa` and manually evaluate:

```text
epsilon(z) = epsilon0 + z*kappa
sigma(z) = D*epsilon(z)
```

at BOTTOM/MIDSURFACE/TOP. Verify sign reversal, thickness scaling, Poisson coupling and zero terms.

#### BM-004 pressure/resultant free-body

For a planar/faceted patch with known area and normal:

```text
sum F = p*A*n
sum M_O = sum(r_i x F_i)
```

Verify pressure load does not multiply by thickness and no closed-end axial load is inferred unless explicitly modelled.

#### BM-005 slender cantilever strip

When shell BC/load idealization matches Euler-Bernoulli assumptions:

```text
I = b*t^3/12
delta = P*L^3/(3*E*I)
M_root = P*L
sigma_root = M*c/I
```

Use this for global-response sanity and mesh convergence, not point-stress singularities. For moderate-thickness/shear-sensitive comparison, use a Timoshenko/Mindlin reference only if the production formulation actually includes transverse shear.

**Manual acceptance:** hand worksheet values frozen before production execution; signs/units and reference points explicit; production output cannot populate expected values.

### LEG-008 — published benchmark execution

Minimum shell family:

1. **Scordelis-Lo roof** — membrane/bending coupled curved shell; compare the exact published displacement QoI.
2. **Pinched cylinder** — severe bending/membrane/shear challenge; exact radial displacement QoI and symmetry/BC custody.
3. **Twisted beam** — warped/distorted geometry response; regular and intentionally distorted meshes.
4. Add a plate-bending case and hemispherical/pinched-shell case if required to cover MITC formulation claims represented by the production route.

**Mesh ladder:** normally at least four refinement levels where the benchmark definition permits, e.g. `2x2`, `4x4`, `8x8`, `16x16` equivalent topology. Record DOFs/elements, QoI, relative error and observed convergence.

**Distortion ladder:** regular, skew/trapezoidal, and warped/distorted variants where supported by the published case. Do not silently alter geometry between methods.

**Thin-limit ladder:** representative thickness ratios spanning moderate to very thin response (target order `t/L ~ 1e-1 ... 1e-4` where the published problem permits). Examine whether error grows as thickness decreases — a locking falsifier.

**Acceptance is vector-valued:** published QoI agreement + convergence trend + residual/equilibrium/energy + no spurious modes + distortion robustness. One matching scalar does not qualify an element.

## 6. Tolerance policy

Tolerance ownership remains separate from implementation.

Use:

- near-machine/scale-aware tolerance for exact algebraic invariants where conditioning allows;
- analytically derived truncation/integration tolerance for closed-form comparisons;
- explicit convergence/error criteria for mesh-dependent global QoIs;
- published/reference uncertainty where authoritative;
- no tolerance relaxation solely because current production misses the target.

Any proposed tolerance change is a separate authority change and stops automatic progression.
