## Implemented contract

The new `emp1-engineering-review-record/v1` is an immutable human engineering-review attestation bound to one exact retained EMP.1 evidence set.

Bound identities:

```text
sourceHash
loadTransferResultHash
sectionScreeningResultHash
localCorrelationResultHash
assessmentSemanticHash
routeAuthorityHash
```

The source/A/B/C values must exactly match `emp1-assessment/v1.parents` before a review record can be created. Route authority must carry both the retained workbench route-authority hash and a retained snapshot whose `semanticHash` equals that hash.

The assessment currently has no retained top-level semantic hash, so this module creates a review-local deterministic semantic identity of the immutable assessment value. It does not mutate `emp1-assessment/v1` or replace any existing parent/result hash.

## Review states

```text
NOT_REVIEWED
REVIEW_ACCEPTED
REVIEW_REJECTED
REVIEW_STALE
```

Any change to one of the six bound identities makes a previous accepted/rejected review `REVIEW_STALE`. The original disposition is retained as history but is no longer current.

## Review identity

The record uses the repository canonical semantic-hash primitive only to create:

- deterministic review semantic identity; and
- review-local assessment identity.

This is not a cryptographic signature or professional seal.

## Authority boundary

Review acceptance explicitly does not create:

- source authority;
- method authority;
- applicability authority;
- numerical authority;
- code compliance;
- release/deployment authority;
- cryptographic seal authority.

No WRC source/applicability/route/numerical/oracle/release/workflow owner file is changed.
