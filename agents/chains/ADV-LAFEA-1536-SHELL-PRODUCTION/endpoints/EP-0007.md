### Critical mechanics correction made in this batch

The first adapter draft incorrectly treated MITC `betaX/betaY` as physical rotations about local X/Y. The element kinematics actually require:

```text
betaX = omega_y
betaY = -omega_x
```

because `u=u0+z*betaX`, `v=v0+z*betaY`. For a rigid rotation this yields `gamma_xz=betaX+w_,x=0` and `gamma_yz=betaY+w_,y=0`. Reusing physical rotation rows directly would have created spurious transverse-shear energy.

The adapter now derives MITC beta rows from the existing physical tangent-rotation map and retains both mappings as evidence. Rigid-body energy and beta rigid-reproduction are fail-closed qualification checks.
