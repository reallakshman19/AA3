## Refined diagnosis

The executable failure refines EP-0022: the immediate blocker is upstream of the LEG-011 controller change.

`createEmp1WorkbenchQualificationSample()` builds a raw A fixture, then calls `executeLafeaStage('LAFEA.1', aDocument)`. `executeLafeaStage()` normalizes the document and retains that normalized value as `execution.source`. The factory then calls `refreshEmp1BSourceEvidence({ aDocument, aExecution, ... })` with the original raw A document. `refreshEmp1BSourceEvidence()` requires semantic equality between `execution.source` and the retained A document and throws `EMP1_A_CURRENT_QUALIFIED_RESULT_REQUIRED` when they differ. The factory can therefore fail before returning a sample; this explains why A/B/runInput are all absent in the browser observation.

Authority-safe next repair should normalize the qualification A document through the same LAFEA.1 workbench normalizer before executing it and before using it as the retained A document. It must still return source documents only, not privileged execution evidence.
