## Live technical ground truth

- `mitc4-element.js` already implements explicit `MITC4_QUAD4_SHELL_V1`, 20 local DOF, Reissner-Mindlin membrane/bending/shear, 2x2 Gauss integration, four tying points, positive-Jacobian rejection and `5/6` shear correction.

## Intended adoption architecture

1. Introduce a separate versioned experimental MITC canonical model/evidence boundary; do not weaken or overload `local-shell-model/v1`.
2. Model topology is explicit per element: MITC4 QUAD4 or MITC3 TRI3 fallback; no topology inference that changes formulation silently.
3. Reuse existing MITC stiffness functions as the single formulation authority; adapter code constructs basis/transformation/evidence but does not copy formulas.
4. Reuse shared shell sparse/PCG assembly/solve infrastructure where the generalized five-DOF ordering is compatible.
5. Implement formulation-aware consistent pressure mapping: Q4 by shape-function integration; MITC3 by consistent TRI3 integration. Resultant force and first moment are independent parity oracles.
6. Implement MITC recovery evidence for membrane strain/stress, curvature/bending stress, transverse shear strain/stress and explicit surface quantities. Preserve current `inPlaneVonMises`; any 3D invariant is out of scope unless independently authorized/qualified.
7. Add shared-case regression across CST/DKT and MITC in the thin limit and physically expected divergence at moderate thickness.
8. Label every MITC adoption result `ROUTE_STATUS: EXPERIMENTAL_NONPRODUCTION` and `CONTRIBUTES_TO_LAFEA4_PRODUCTION_QUALIFICATION: FALSE` until a later promotion leg.

### Takeover qualification pack

#### Q1 — Current production barrier

Therefore a QUAD4 MITC document cannot cross canonicalization and `calculateLocalShell()` cannot dispatch MITC.

#### Q2 — MITC mechanics custody
Anchors: `mitc4-element.js`, `mitc3-element.js`, constitutive/transformation modules and existing MITC checks.
MITC4: 4 nodes x `[u,v,w,betaX,betaY]` = 20 DOF; 2x2 Gauss; membrane factor `t`, bending factor `t^3/12`, transverse shear rigidity `(5/6)Gt`.
MITC3: 3 nodes x same 5 DOF = 15 DOF; three-point triangle rule; same constitutive thickness/shear scalings.
Required invariant: adapter transforms existing local stiffness/evidence; it does not reimplement these equations.
Fail if: stiffness or shear-correction formulas are duplicated in the adapter.

#### Q3 — Dispatch/fallback authority
Each experimental element must carry explicit `formulation` and `topology`. MITC4 accepts exactly 4 ordered corners; MITC3 accepts exactly 3. MITC3 is selected only when source/canonical input explicitly requests it. No mesh or solver failure may trigger MITC4->MITC3 substitution.
Falsifier: malformed topology or unknown formulation must fail closed before stiffness calculation.

#### Q4 — Independent validation
MITC4 existing oracles: square/distorted rigid modes, symmetry, positive semi-definiteness, inverted-Jacobian rejection and Timoshenko cantilever no-locking across t/L 1e-1..1e-5. MITC3 has its own independent fallback checks. Adoption adds basis covariance: rigid translation/rotation must remain zero-energy after global transformation, and transformed K must retain symmetry. Thin-limit shared cases should approach CST/DKT where transverse shear contribution vanishes; moderate thickness should show the expected additional physical shear compliance rather than being forced to numerical equality.
Fail if: MITC output is its own sole oracle.

#### Q5 — Minimal first patch
Expected new owner seams: experimental MITC canonical contract + element adapter/evidence + focused tests. Existing element modules remain formula owners. No load mapping, global solve, recovery, stage registry, presenter or UI change in the first material batch. Roll back if v1 CST/DKT hashes/behavior change, MITC3 becomes implicit, transformed stiffness loses rigid/symmetry invariants, or adapter needs duplicated formulation equations. NO-PATCH if existing five-DOF basis machinery cannot represent MITC rotations without changing their physical meaning; escalate that as an authority/design decision rather than coercing compatibility.
