## Observed problem
The frozen M3 rule demands that every worst shape metric hold or improve at every refinement. Current shell meshes have progressively smaller actual element lengths and conforming seams, but their worst shapes deteriorate while median shapes improve. Every element remains within production blocking bounds. Passing shape criteria alone would still say nothing about solution accuracy.

The T6 gate reports the normalized reference-column Jacobian. The same affine triangle can report a different value after cyclic corner numbering. This is a reproduced property of the current metric, not proof that the M3 T6 failure has that exact cause. Changing the production metric would require its own engineering review.

## Concrete proposed acceptance revision
Create a new, separately identified policy version and retain the existing fixture and failed evidence as immutable v1 provenance. Do not relabel or replace the previous run.

1. Keep existing M0-M2, frozen geometry, physical probes, boundary constraints, source custody, requested refinement ladder, unique mesh hashes, increasing node/element counts and resource limits.
2. Add finite, strictly positive measured characteristic-length distributions from production element quality evidence for each level and family. Require actual maximum characteristic length to decrease between consecutive levels. Do not infer actual refinement from the requested size or element count alone, or require exact factor-two actual refinement from an unstructured producer.
3. Keep every existing production BLOCK threshold, nonpositive-Jacobian rejection, shell seam constraint and adjacent-size ratio limit unchanged. Retain warnings with the existing meaning, including shell h/t warnings.
4. Retain the three worst-shape trend checks and their FAIL observations as explicit diagnostics. In the new policy, these observations alone do not block advancement when all independent measured-refinement and unchanged safety gates pass. Report the policy version and both diagnostic and advancement status clearly; never overwrite a FAIL with a PASS.
5. Before enabling advancement, exercise negative cases for unchanged actual mesh size despite increasing count, nonfinite/nonpositive lengths, failed quality gates, broken seams, missing evidence and changed source pins. Each must stop the applicable stage and leave M4 blocked.
6. M4 remains behind a complete PASS prefix under the explicitly authorized new policy. Preserve every existing independent physical expected value, residual/reaction/probe tolerance, source hash and load definition. Execute at a clean committed head; retain any new failure. M4's present affine checks are limited patch tests; stage completion still requires the non-affine and curved practical cases in the children.
