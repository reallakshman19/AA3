## Objective

Deliver an EMP-tab-only benchmark evidence capability that exposes existing CAUx comparison evidence and later admits a frozen PV Elite comparator without allowing either benchmark to become WRC method, engineering-use, code, release, or deployment authority.

## Constraints fixed before coding

1. Work only on EMP/EMP.1 modules and chain-local custody.
2. Do not touch generic FEA benchmark infrastructure, LAFEA.3+, Load Calc, project-data, support-site, or `.github/workflows/**`.

4. Do not rewrite CAUx frozen expected values or tolerance.
5. Do not invent PV Elite values. PV Elite remains `REFERENCE_NOT_AVAILABLE` until an exact report/input/version is retained and frozen.
6. Avoid active exact-file overlap with PR #1622, #1624, and #1618.

## Stage 1 — Core benchmark evidence projection (first material leg)

Expected new files only:
- `src/core/emp1/emp1-benchmark-evidence-projection.js`
- `scripts/emp1-benchmark-evidence-projection-check.mjs`

Do not export through `src/core/emp1/index.js` while PR #1618 owns that file.

### Projection responsibility

Pure read-model function. It receives already-retained benchmark/reference metadata, freeze state, route relationship, and already-computed comparison quantities. It returns a deep-immutable `emp1-benchmark-evidence/v1` projection.

Minimum output:
- benchmark/comparator/case identity;
- authority role;
- exact source/freeze evidence;
- method and route relationship;
- per-quantity reference, EMP value, absolute/relative difference, tolerance, tolerance basis, source locator and status;
- summary: count, worst difference, governing-point agreement, source qualification state;
- explicit false authority flags;
- limitations/blockers.

### Fail-closed rules

Reject or classify unavailable when:
- comparator/source identity is missing;
- frozen-definition proof is inconsistent;
- expected-value freeze says production output influenced the definition;
- tolerance basis is missing for a claimed qualified comparison;
- route authorization fields contradict the supplied route relationship;
- quantity units/IDs are malformed;
- comparator tries to claim WRC method/code/release authority.

PV Elite pending state is a valid projection state, not an exception.

### Checker coverage

Use real current CAUx authority/freeze identities plus controlled structured comparison fixtures. Verify:
- CAUx 8-point qualified-comparison projection;
- source re-observation pending remains visible simultaneously;
- interpolated route remains `engineeringUseAuthorized=false`;
- no generic `PASS` authority promotion;
- PV Elite missing-source → `REFERENCE_NOT_AVAILABLE`;
- forged authority flag rejection;
- freeze/tolerance/source tamper rejection;
- deep immutability;
- static guards: no WRC evaluator/Table-5/interpolation execution imports in projection.

Exit gate:
- focused checker encoded;
- no UI file touched;
- no source/oracle/route authority changed.
