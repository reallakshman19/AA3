4. ARCHITECTURAL INTERPRETATION
======================================================================

The current experimental selection:

    input.kind === 'FRAME' && teeModifier === null

is a controlled A/B boundary, not the intended permanent physical boundary.

Long-term architecture should be:

    governed pipe section/material
        -> governed base beam constitutive law
        -> component-owned mechanics
        -> offsets/transforms
        -> assembly
        -> Schur condensation where required

Transverse shear is a property of flexible pipe beam mechanics. A tee does not
make adjacent pipe Euler-Bernoulli. A reducer condenser does not remove shear
flexibility. A bend incoming straight is still straight flexible pipe.

Component-specific mechanics must compose with the common beam law without
double ownership. Example: if B31J junction flexibility is represented by an
explicit rotational spring/compliance mechanism, the same flexibility must not
also be embedded through a second branch weakening factor.

Schur condensation is mathematically neutral:

    Kc = Kbb - Kbi Kii^-1 Kib
    fc = fb  - Kbi Kii^-1 fi

It preserves whatever physics was assembled internally, correct or incorrect.
Therefore reducer internal cylinders must eventually use the qualified base
beam law before condensation, but only after the complete reducer stiffness +
load ownership model is independently qualified.

    MODULUS = HOT_MOD1 = 203395008 kPa.

Important export-boundary distinction:
- CAESAR documents TEMP_EXP_C1..C9 as a "thermal expansion coefficient or
  temperature" input field family,
- for THIS locked job, the value 120 establishes TEMP_EXP_C1 as operating
  temperature in degrees C,
- no separate pipe-element field exports the CAESAR material-library mean CTE
  or the read-only derived thermal strain.

Misleading candidate fields were independently classified:
- INPUT_NOZZLES_API650.THERM_EXP_COEFF exists in schema but the table has zero
  rows and it is API-650 nozzle authority, not pipe material CTE,
- INPUT_REDUCERS.ALPHA is reducer transition slope in degrees,
- INPUT_ALLOWABLES ALPHA_H / ALPHA_FAB / ALPHA_GW are code-specific non-thermal
  fields and are inactive for this B31.3 job,
- no ACCDB column contains BOURDON.

Decision:

    I017 ACCEPTED as an authority/export-boundary finding.

The reusable solver cannot recover CAESAR's 21 -> 120 C A106 Grade B
material-library expansion value from a separate ACCDB CTE/strain field because
that derived authority is not exported here. The profile must therefore carry a
versioned external material authority and fail closed if its provenance is
missing.

I017 authorizes NO numeric CTE change. In particular, the I009/I010 inferred
~12.23199e-6/K value remains diagnostic-only until independently reproduced from
a source-authoritative material record.

Required provenance for eventual thermal profile authority:
- CAESAR version/build,
- supplied material database identity and hash (cmat.bin),
- user material database / UMD identity and hash or explicit none,
- material number and name,
- piping code ID/edition,
- reference temperature 21 C,
- target temperature 120 C,
- interpolation bracket and method,
- resulting mean CTE and/or derived thermal strain.
