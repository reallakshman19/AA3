## Delivered authority boundary

The intake composer owns only binding of the current normalized LAFEA.3 engineering source to declared mesh-independent `lafea-analysis-geometry/v1`, `lafea-continuum-analysis-domain/v1`, and sealed geometry evidence. It derives source physical-case identities, requires source-compatible single-region material and uniform thickness, enforces the current canonical geometry-unit boundary, and preserves feature-based attachments.

The new public `registerContinuumGeometryIntake()` action prevalidates the complete package before domain/geometry custody mutation, activates the existing domain-first profile, registers the existing domain and geometry-evidence contracts, and verifies committed parent hashes. It creates no analysis mesh, performs no feature-to-mesh lowering, executes no solver, and grants no release authority.

The focused check is designed to exercise the production store using a 5-vertex 11,400 mm^2 polygon and a multiply-connected 10,400 mm^2 OUTER-minus-HOLE domain. It checks canonical permutation invariance, bad material rejection, unknown physical-case rejection, forbidden mesh-authority payload rejection, existing automatic T6 generation, independent material-area reconstruction, deterministic replay, preflight and solver-model parent binding.
