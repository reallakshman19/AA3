2. `loadMockData` registered mesh-independent geometry only for LAFEA.3; pressing Sample for LAFEA.4/.5 did not create the stage-specific parent required by governed generation.
3. Both the Discretization profile control and the prominent top quick-mesh action built LAFEA.3-style mesh profiles for shell stages instead of preserving the shell-family identity.

The synthetic PNG reconstructions produced during investigation are **not engineering evidence and must not be used as app screenshots**. The visible Sample is `CYLINDRICAL_PIPE_SHELL_BENCHMARK` from `scripts/lafea.4-fixtures.mjs`:

PR #1158 now creates an exact source-bound analytic cylindrical midsurface for this Sample and verifies every Sample node lies on/in the declared cylinder patch before registering the parent. LAFEA.4 then uses the governed `CST_DKT_TRI3_THIN_SHELL_V1` automatic shell mesher from that parent.

### LAFEA.5 — Trunnion footprint

The visible Sample is `TRUNNION-WORKFLOW-1` from `scripts/lafea.5-fixtures.mjs`:

- caller-authored host-shell `shellTemplate`;
- 24 shell nodes;
- 24 TRI3 elements;
- 12-sector footprint band;
- the `Fxx` rim follows the pipe/trunnion cylinder intersection curve;
- the `Oxx` rim preserves the caller-authored offset geometry.

This geometry is **not** equivalent to the generic rectangular periodic-cylinder contract. Remeshing it as a rectangular cylinder would alter the Sample geometry and break the stage's caller-authored host-shell authority.

PR #1158 therefore uses **lossless governed source-mesh adoption** for LAFEA.5:

- node IDs preserved;
- node XYZ coordinates preserved;
- element IDs preserved;
- TRI3 connectivity preserved;
- no topology mutation;
- no coordinate mutation;
- governed mesh-quality gates evaluated at adoption;
- no local/adaptive refinement.

This is consistent with LAFEA.5 stage authority `CALLER_AUTHORED_HOST_SHELL_FOOTPRINT_ONLY` and with the existing trunnion-footprint solver, which consumes the caller-authored shell template directly.

The v2 quality evaluator uses 3D edge lengths and 3D cross products for shell triangles. An independent formula check against the exact Sample coordinates gives minimum scaled Jacobian about `0.3194`: above the qualified block threshold `0.2`, while some elements are expected warnings below `0.6`. Only an executed current-head run may establish the final retained evidence result.

The current source engineering scene is `XY_ENGINEERING` orthographic. This matters particularly for LAFEA.5: paired `Fxx/Oxx` nodes can share X/Y and differ in Z, so the source preview can collapse depth visually. This is an existing viewport projection limitation and must not be hidden by fabricated 3D imagery.

The retained LAFEA.5 mesh uses the exact same 3D source nodes and therefore its XY overlay remains geometrically aligned with the actual source projection even though depth is not visible. A separate 3D source/mesh viewport enhancement would require its own scope/qualification.
