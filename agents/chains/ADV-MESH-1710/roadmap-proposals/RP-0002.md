## Concrete candidate change
Replace only the raw sign classification in classifyBehavior:

```diff
-  const signs = deltas.map((d) => Math.sign(d));
+  const scale = Math.max(...values.map((value) => Math.abs(value)));
+  const roundoffBand = scale * (Number.EPSILON * 256);
+  const signs = deltas.map((delta) => (
+    Math.abs(delta) <= roundoffBand ? 0 : Math.sign(delta)
+  ));
```

This is a proposed scale-relative numerical policy, not a proven solver forward-error bound. The factor 256 reuses the repository benchmark runner's existing roundoff convention; adopting it in the shared classifier requires explicit review. The scale deliberately omits max(1, scale), so changing units does not introduce an absolute physical tolerance. Do not round, clamp, replace or rewrite response values. Keep the finest-level relative-change calculation and every DEFAULT_LIMITS value unchanged. Only insignificant sign changes become zero for behavior classification.
