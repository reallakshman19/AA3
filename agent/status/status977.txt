2. QUALIFIED / ACCEPTED FINDINGS SO FAR
======================================================================

A. Diagnostic method

The strongest diagnostic is prescribed-DOF element/source replay:

    q = K d_CAESAR - f_equiv - f_initial

For source elements/substructures, CAESAR endpoint displacement/rotation is
prescribed and LFEA end actions are recovered using the same source-action
coordinate/sign conventions as the benchmark. For subdivided components,
internal artificial DOFs are solved/condensed while the physical source
endpoints remain prescribed.

This removes the global displacement solution from the causal question and
asks directly whether the local constitutive/load model maps CAESAR motion to
CAESAR end action.

B. Source-4 decomposition

For L19 source 4 near node 20090:
- axial replay is essentially correct (about 0.009 N residual),
- transverse FY/MZ replay remains materially wrong under Euler-Bernoulli,
- transverse pressure/initial-strain contribution is zero,
- therefore the dominant source-4 transverse defect resides in the stiffness
  response rather than Bourdon or pressure-axial initial strain.

C. Missing transverse shear mechanism

The existing frame kernel already contains a governed Timoshenko formulation.
Replaying source 4 with transverse shear deformation strongly improves FY/MZ
while leaving axial/torsional mechanics invariant.

The strongest population evidence is the I014 plain-FRAME replay:
- 50 ordinary plain FRAME sources,
- 400/400 L19 local transverse end-action components improve,
- zero transverse regressions,
- zero local axial/torsion drift,
- L19 transverse RMS residual approximately 1080.342 -> 21.787,
- L20 transverse RMS residual approximately 4824.048 -> 66.350.

This qualifies the MECHANISM conclusion:

    Missing transverse shear deformation in ordinary flexible-pipe response
    is strongly supported.

D. I015 controlled system A/B

I015 applies the governed Timoshenko pipe-frame formulation only to the
controlled plain-FRAME/no-tee population so the system experiment changes one
mechanics family at a time.

L19 result on locked BM4_NL:
- restraint failures: 1 -> 0,
- node 20090 FY: approx -1932.836 N -> -1801.623 N,
- CAESAR node 20090 FY: -1659.837 N,
- node 20090 relative error: approx 16.45% -> 8.54%,
- displacement/rotation failures: 74 -> 66,
- displacement/rotation failing nodes: 52 -> 45,
- displacement/rotation normalized RMS: approx 0.4111 -> 0.3464,
- source-action normalized RMS: approx 0.05405 -> 0.05304,
- 12/12 bend coverage preserved,
- node 20090 incident-action/reaction closure remains at numerical roundoff.

The L19 restraint gate is therefore closed by this controlled A/B.

E. Evidence discipline retained

3. IMPORTANT LIMITATIONS / NOT YET QUALIFIED
======================================================================

A. The I015 selection boundary is NOT the final architecture

Current controlled experiment boundary:

    plain FRAME && no tee modifier -> Timoshenko

This was useful experimental containment, but transverse shear flexibility is a
property of flexible pipe mechanics, not the semantic label "plain FRAME".

Long-term target architecture should be:

    governed pipe section/material
        -> governed base beam law
        -> component-owned mechanics
        -> rigid offsets/transforms
        -> assembly
        -> Schur condensation where required

Branches/tees, bends, reducer internal cylinders, and other flexible pipe
subcomponents should consume the common governed beam law unless their theory
explicitly requires a different base beam. They should add only the component
physics they own.

No double ownership is allowed. Example: if B31J junction flexibility is owned
by an explicit rotational spring/compliance mechanism, the same flexibility
must not also be embedded through another branch multiplier.

B. Exact CAESAR shear-factor authority remains a separate gate

The I013/I014/I015 chain is very strong evidence for NONZERO transverse shear.
Mechanism identification must remain separate from exact parameter authority.

Later CAESAR-specific authority indicating a commercial pipe shear coefficient
of 2 (mapping naturally to As=A/2, kappa=0.5 in the kGA convention) must be
reconciled with the current controlled I015 candidate/evidence before any
production-wide shear profile is finalized.

Do not inverse-fit kappa against individual CAESAR output rows. Different rows
requiring inconsistent inverse kappa values is evidence of other custody or
component-mechanics issues, not a license to tune one global scalar.

C. L19 source-action residual cluster remains

I015 improves aggregate source-action RMS but threshold failures move 20 -> 23.
A carried cluster appears around sources 9-11 MZ at roughly 11.5-12.7% while
three previous failures resolve.

This cluster is explicitly pending. It does not invalidate the qualified
ordinary-pipe shear mechanism, but L19 source-action closure is not complete.

D. L20 is NOT qualified

I015 L20 restraint result:
- baseline failures: 5,
- I015 failures: 6.

Key I015 L20 failing restraint components include:
- 20350 FY: about 23.29%,
- 20390 FZ: about 11.54%,
- 20550 FZ: about 23.63%,
- 22140 FX: about 13.20%,
- 22310 FZ: about 10.65% (new threshold crossing),
- 22490 FX: about 10.75%.

The structural shear correction does not solve the thermal case. L20 must be
investigated through the L20-L19 thermal increment rather than by retuning the
qualified L19 transverse mechanics.
