## Current hypothesis

WRC 537 primary nomenclature directly defines its directional reference with respect to an axis normal to the shell through the center of the attachment. For cylindrical shells it then resolves longitudinal/circumferential directions with respect to the cylinder axis.

This can qualify a bounded **shell-normal reference-axis statement**.
