### Corrected engineering evidence

The first sparse implementation used the maximum individual element symmetry residual as the assembled global residual. That can understate the actual assembled asymmetry when small per-element asymmetries accumulate on the same global DOF pair.

`src/core/local-shell/assembly.js` now accumulates the signed lower-minus-upper contribution for each assembled global off-diagonal pair and reports the maximum absolute assembled difference. This reproduces the semantic quantity used by dense `symmetryResidual(K)` without allocating a dense matrix.

`scripts/lafea.4-solver-loads-check.mjs` now contains a controlled two-contribution falsifier in which each contribution has the same sub-tolerance asymmetry. The test requires sparse assembled symmetry evidence to match dense assembled symmetry evidence, proving accumulation rather than the previous per-element maximum shortcut.
