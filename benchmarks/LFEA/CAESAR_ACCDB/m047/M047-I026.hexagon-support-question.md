# M047-I026 — Hexagon CAESAR II metallic-pipe transverse-shear authority question

Target product/version: **CAESAR II 14.00**  
Target analysis: **static piping flexibility, ordinary isotropic metallic pipe**  
Target code/job context: **ASME B31.3-2022 / B31J-2017, A106 Grade B**

## Question for Hexagon engineering/support

For an ordinary straight isotropic metallic pipe element in CAESAR II 14.00 static piping analysis:

1. Does the element stiffness formulation include **transverse shear deformation** in addition to Euler-Bernoulli bending deformation?
2. If transverse shear is included, what **effective shear area / shear-correction coefficient** is used for a hollow circular pipe section?
3. Is that coefficient:
   - a fixed constant;
   - dependent on OD/ID or wall-thickness ratio;
   - dependent on Poisson's ratio; or
   - calculated by another section formula?
4. For ordinary isotropic metallic materials, how is **shear modulus G** obtained from the material properties used by the piping element? Is it derived from E and Poisson's ratio, and if so what exact relationship is used in the stiffness formulation?
5. Does this transverse-shear formulation apply unchanged to the **base beam stiffness** beneath:
   - bend/elbow flexibility and pressure-stiffening corrections;
   - ASME B31J tee/run/branch rotational flexibility; and
   - reducer representations,
   or are any of those component formulations built from a different base beam assumption?
6. Is there a CAESAR II 14 technical/theory reference, verification document, equation set, or other vendor-authored source that states these element-stiffness equations?

## Why the exact implementation is required

We are qualifying an ACCDB-driven independent linear FEA implementation against a locked CAESAR II 14 job. Prescribed-DOF evidence shows that transverse shear is mechanically significant, but we are intentionally **not inverse-fitting** a shear coefficient to CAESAR reactions or displacements. We need the implementation authority above before selecting any numeric coefficient or effective shear area.

The current experiment used a Cowper thin-annulus-based `kappa=0.53` only as mechanism evidence. It is **not being asserted as CAESAR authority**.

## Requested response form

Any one of the following is sufficient if it is explicitly applicable to CAESAR II 14 ordinary isotropic metallic piping:

- the element stiffness / shear-area equations;
- a technical manual or verification-reference section;
- a vendor engineering statement identifying the implemented formula; or
- confirmation that transverse shear deformation is not included in this element path.

Please distinguish the ordinary metallic-pipe formulation from the documented **FRP Ratio Shear Modulus : Elastic Modulus** configuration, which is not the authority being requested here.
