## Friction stiffness

`FRICT_STIF = 1.0E6` is CAESAR's internal-English friction stiffness in lb/in. The ACCDB carries its own internal-to-displayed translational conversion:

`INPUT_UNITS.CTRANS = 1.751270055770874 N/cm per lb/in`

Therefore the governed SI value is:

```text
1.0E6 lb/in × 1.751270055770874 × 100 cm/m
= 1.751270055770874e8 N/m
```

The checked-in solver authority already reads `CTRANS`; generated configuration evidence that still reports `1.0e8 N/m` is stale and must be regenerated before citation.

## Configuration authority

Resolution remains lowest-to-highest:

`overall/global default < individual-file setting < load-case setting < model input`

The model coefficient and load-case multiplier remain separate governed quantities:

`effective friction = INPUT_RESTRAINTS.FRIC_COEF × FRICTION_MULTIPLIER`

The friction entity is one restraint row, not a whole node. Capacity uses that restraint's signed normal projection `|R·n|`; a co-located guide or line stop does not contribute to that normal and removes its direction from the free friction plane.

## L15 boundary

L15 is not a nonlinear solve. It is the algebraic result combination:

`L15 = L7 - L13`

L7 and L13 must converge independently. L15 has no independent friction multiplier, stiffness, active set, load stepping, or nonlinear convergence settings.

## Direction-rule correction status

The source-derived accuracy RCA in `reports/lfea-m047-stage2-accuracy-rca.md` supersedes the earlier assumption that CAESAR parity requires the retained-spring force to follow the current elastic stretch.

The current solver profile declares:

`slipDirectionRule = UNIT_RELATIVE_TANGENTIAL_DISPLACEMENT_V1`

but the return-map implementation currently makes the force anti-parallel to `elasticTangentialStretch = u_t - u_slip` and gates that same identity. Inspection of the committed real L13 ACCDB artifact shows representative two-dimensional CAESAR friction vectors are anti-parallel to the **total relative tangential displacement** to machine precision. The next one-mechanic tuning variant must therefore test total relative tangential displacement as the capped-force direction while keeping every other mechanic and acceptance gate fixed.

This is an RCA finding, not a new qualification claim; the next real-ACCDB run decides whether it is adopted.

## R1 reference-resolution diagnostic

With the governed stiffness, half of a 0.001 mm printed displacement step corresponds to:

```text
1.751270055770874e8 N/m × 0.0005 mm × 1e-3 m/mm
= 87.5635 N
```

This is a diagnostic for displacement-derived friction/stiffness inference. It does not widen the force comparison tolerance. Node 21930 is below this displacement-derived force floor; node 20550 illustrates that even a force above the floor can have large relative displacement-print uncertainty.
