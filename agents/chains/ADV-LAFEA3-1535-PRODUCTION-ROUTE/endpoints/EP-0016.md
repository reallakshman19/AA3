1. **Convergence backend not composed into visible controller.** `LafeaWorkbenchController` instantiates `createLafeaWorkbenchOrchestratorStore`; convergence-aware `createLafeaWorkbenchStore` exists separately. Visible state therefore cannot own the completed convergence custody/publication transaction.
2. **No Convergence workflow area.** Canonical guided steps are Source/Model/Profile/Materials/BCs/Loads/Discretization/Preflight/Authorization/Run/Results and operator grouping is only Model -> Mesh -> Solve -> Results.
3. **Post-solve banner contradicts publication authority.** Backend `gateLafea3ResultPublication()` requires convergence `CURRENT_PASS`; visible next-action banner displays `Analysis result retained` and `Review retained results` whenever `stage.execution.status === QUALIFIED`, regardless of convergence readiness.
4. **Ordinary geometry intake is orphaned from UI.** `registerContinuumGeometryIntake()` exists on orchestrator API; controller exposes no corresponding method/handler. LAFEA.3 source form edits an existing node/material/element/constraint document but does not expose arbitrary vertices + LINE/CIRCULAR_ARC segments + OUTER/HOLE loops + feature attachments. Fallback is stage JSON/raw JSON.
5. **Visual order contradicts workflow order.** Main content appends next action, engineering overview, then CAE workspace (viewport + meshing + solve readiness), and only afterwards context containing Model inputs and analysis settings. A fresh user therefore sees Mesh/Solve surfaces before the Model inputs that own them.
6. **Solve icon is semantically overloaded.** Operator `SOLVE` area uses a play-triangle icon but contains Numerical preflight + Authorization + Run. Clicking it can navigate to a prerequisite/evidence target, not execution.
7. **Run is duplicated.** Toolbar `Validate and calculate`, next-action `Run analysis`, and engineering-overview run action expose multiple apparent execution entrances.
8. **Governance/stage taxonomy dominates normal UX.** `LAFEA.3`, `Technical custody detail`, and always-visible `Release authority` compete with the engineer's task sequence.
9. **Next-action logic can advance to meshing too early.** Once any source document exists, the banner primarily tests mesh evidence and can present `Step 2: Configure analysis mesh` without first making the Model-area blockers the primary action.
10. **No visible convergence ladder/state.** There is no operator surface for mesh levels, probe quantity/value, delta, classification/order/GCI, stale/current or `CONVERGENCE_NOT_ACHIEVED`, despite backend custody existing.

These are workflow-semantics defects; icon redraw alone must not be accepted as remediation.
